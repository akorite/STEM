📋 Instruksi OTA

  1. Pilih partisi OTA. Arduino IDE → Tools → Partition Scheme → Minimal SPIFFS (1.9MB APP with OTA/128KB SPIFFS).
  2. Export firmware. Sketch → Export Compiled Binary, lalu ambil file .bin.
  3. Upload. Pilih file dan tekan Upload & Reboot. Relay mati otomatis; tunggu ±10 detik lalu buka dashboard.
Jangan cabut daya saat upload. Jika gagal, cek partisi dan ulangi dengan file .bin yang benar.

🛟 Jika OTA Gagal

  1. Cek partisi. Pastikan memakai Minimal SPIFFS (1.9MB APP with OTA/128KB SPIFFS), bukan partition tanpa OTA.
  2. Export ulang. Sketch → Export Compiled Binary, lalu pilih file .bin yang baru.
  3. Pulihkan lewat USB. Jika web OTA tetap gagal, upload sekali dengan kabel USB, lalu coba OTA lagi.
  4. Baca log. Serial Monitor 115200 akan menampilkan pesan [OTA] dan penyebab kegagalan.
